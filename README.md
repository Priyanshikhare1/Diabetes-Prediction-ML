# Diabetes Prediction using Machine Learning

## Overview

This project predicts whether a person has diabetes using machine learning based on medical features such as glucose level, BMI, age, and blood pressure.

## Dataset

The dataset used is the Pima Indians Diabetes Dataset.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Machine Learning Model

Logistic Regression

## Project Workflow

1. Data loading
2. Data exploration
3. Data visualization
4. Feature selection
5. Train-test split
6. Model training
7. Model evaluation
8. Prediction

## Result

The model achieved around 78% accuracy.
